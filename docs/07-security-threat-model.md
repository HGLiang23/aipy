# 安全威胁模型

## 1. 信任边界

    浏览器 -> API -> 应用服务 -> PostgreSQL/Redis/Object Storage
                             -> Celery Worker -> 模型/采集/发布供应商

浏览器输入、采集内容、上传文件、模型输出、平台回调和队列消息均视为不可信。
租户上下文只能从验证后的服务端会话恢复。

## 2. STRIDE

| 类别 | 主要威胁 | 首版控制 |
|---|---|---|
| Spoofing | Token 伪造、服务身份冒用 | 强签名 JWT、短期 Access Token、Refresh 轮换与撤销 |
| Tampering | 修改产物、审批、队列消息 | 不可变版本、哈希、乐观锁、Outbox、幂等键 |
| Repudiation | 否认编辑、批准或发布 | 只追加审计、操作者/租户/Trace/前后版本 |
| Information Disclosure | 跨租户、密钥或正文泄漏 | 后端授权、RLS、密钥引用、日志脱敏、签名下载 URL |
| Denial of Service | 采集洪泛、Token 消耗、队列堆积 | 配额预占、并发上限、超时、熔断、租户限流 |
| Elevation of Privilege | 越权审批、发布、平台管理 | 默认拒绝、数据范围、状态策略、职责分离 |

专项威胁：

- 采集器必须阻断私网、环回、云元数据地址及重定向绕过，防止 SSRF。
- HTML 和富文本必须清洗；上传文件经过类型、大小和恶意内容检查。
- 来源文本中的指令不得成为系统指令，模型工具使用显式允许列表。
- 平台回调必须验签、校验时间窗口并通过 `inbox_event` 去重。
- 发布超时进入 `EXTERNAL_UNKNOWN` 对账，不能盲目重发。

## 3. 数据分级

| 级别 | 示例 | 控制 |
|---|---|---|
| `PUBLIC` | 已发布公开内容 | 完整性和版权追溯 |
| `INTERNAL` | Prompt 模板、工作流配置 | 租户权限、审计 |
| `CONFIDENTIAL` | 未发布文章、来源库、运营指标 | 加密、最小权限、禁止日志正文 |
| `RESTRICTED` | 密钥、Token、密码哈希、个人信息 | Secret Manager、严格脱敏、禁止导出 |

## 4. 保留和删除

- 密钥值不进入业务数据库；密钥引用随凭证生命周期保存。
- Refresh Token 撤销记录保留到 Token 过期后再增加安全缓冲期。
- 模型调用元数据按租户策略保留；正文默认不写调用日志。
- 审计日志保留期长于普通业务日志，租户管理员无删除权限。
- 来源撤权或租户删除使用异步删除任务，覆盖数据库、对象、向量和缓存。
- 备份按同一数据级别保护，删除请求需记录备份自然过期时间。

具体天数由套餐和地区合规策略配置，不在代码中硬编码。

## 5. 日志脱敏

允许记录：ID、状态、耗时、Token 数、费用、错误码、哈希、供应商请求 ID。

禁止记录：密码、JWT、Cookie、API Key、平台 Token、完整正文、完整 Prompt、
身份证号、手机号、邮箱和未脱敏 URL 查询参数。

日志中租户、用户和 IP 使用内部 ID 或受控哈希。异常堆栈必须经过结构化
过滤器，不能直接序列化请求体。

## 6. 上线门禁

- 跨租户允许访问数必须为 0。
- P0/P1 安全扫描问题必须为 0。
- 密钥扫描、依赖扫描、镜像扫描和 RLS 集成测试通过。
- 备份恢复、Token 撤销、SSRF、上传、回调重放和重复发布场景经过演练。
