## 全量代码 Review（后端 57 py + 前端 web/app|lib）

结论：当前代码是「租户/身份/授权骨架 + 三个只读看板 API」，与 `docs/05-mvp-delivery-plan.md`
规划的 AI 内容生产全链路差距是数量级的。静态检查：ruff 43 项告警（E501/UP/B008/E402/I001），
4 个文件未 format（本机无 .venv，临时用 /tmp/aipy-lint 的 ruff 0.16.8 跑的）。

### P0（正确性/安全）
- `apps/api/repositories.py:build_session`：`tenant`/`workspace` 可能为 None，直接取 `.id` 会 500。
- `authenticate` 只校验密码，未校验 `AppUser.status`（DISABLED/LOCKED 仍可登录）。
- `apps/api/dependencies.py:28` JWT secret 有硬编码默认值，且 `.env.example` 未声明 `AIPY_JWT_SECRET`。
- 登录 cookie 未设 `secure`，不随 environment 切换。
- 令牌撤销用进程内 set，多实例失效；且 login 只下发 access_token，refresh token 生成后即丢弃（15 分钟后必重新登录）。

### P1（架构断层）
- `AuthorizationService`（含 SoD、数据范围、工作流态）**完全未接入 API**；repositories 里是
  硬编码 `ADMIN_PERMISSIONS`/`ADMIN_ROLE_LABEL`，所有登录用户都是全量管理员，前端 PermissionGate 是装饰。
- 无写接口；`etag`/`row_version` 已就位但没有 If-Match 并发控制。
- `apps/worker` 只有 celery_app.py，无任何 task；无 ModelGateway/LLM、无工作流状态机、无采集。
- 无 request_id 中间件、无结构化日志、无审计表（但权限清单里有 `audit:view`）。

### 其他
- 测试仅 5 个文件，无 API 集成测试；RLS 集成测试需 PG 环境变量，默认 skip。
- `openapi/openapi.yaml` 手写，无契约测试。
- CORS `allow_origins` 硬编码 localhost:3000。
- 前端 admin/筛选/搜索按钮均为占位（无 onClick/onChange）。

## P1 授权服务接线（已完成，39 passed / ruff / mypy strict 全绿）

- 新增 `src/aipy/modules/authorization/infrastructure/{role_catalog,policy_repository}.py`：
  `role_catalog` 按 `tenant_membership.job_title` 映射角色权限（管理员/编辑/审核员/成员，
  权限码补齐了 `content:pause|rerun|export`、`review:submit`）；
  `SqlAuthorizationPolicyRepository` 从 tenant / membership / app_user 真实状态构造
  `AuthorizationPolicy`（tenant_active、actor_active、TENANT_ALL 授权范围）。
- `apps/api/repositories.py` 重写：删掉硬编码 `ADMIN_PERMISSIONS`，
  `_allowed_actions()` 用 `AuthorizationService` 逐行计算，输出权限码的 action 半段
  （`view`/`approve`）以保住前端契约；`CANDIDATE_ACTIONS` 定顺序保证 UI 稳定。
  资源类型：ContentRun→`content`、HumanTask→`review`、Material→`source`。
- `apps/api/dependencies.py`：新增 `require_claims` / `get_tenant_context` /
  `get_authorization_service` / `get_request_id`；新增 `apps/api/middleware.py`
  （`RequestIdMiddleware`，读 `X-Request-ID` 或生成，回写响应头）。
- 三个列表路由改为依赖 `get_tenant_context` + `get_authorization_service`（保留
  `get_current_session` 作为会话有效性门禁）。
- 新增 `tests/unit/test_authorization_wiring.py`（8 个用例，不依赖 DB）：角色差异、
  租户/成员停用、policy 缺失、SoD 创建者不能 approve 自己的任务。

- `scripts/seed_dev.py`、`scripts/_serve_forever.py` 仍有 E501 且未 format（属 P2 CI 门禁）。

## 本机环境坑（macOS）
- 默认 PyPI 源在本机**极慢/卡死**：`pip install fastapi` 超过 120s 无进展。
  改用 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 后 pydantic/fastapi 秒装。

  Read/Edit 不受影响。装依赖尽量前台跑完或装完就停，别让它长时间占用沙箱。
- 项目根目录 `.venv` 目前是半安装状态（安装被中断），后续要跑测试需重装。
